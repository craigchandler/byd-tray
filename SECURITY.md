# Security reporting

This experimental app uses an unofficial vehicle API. Report vulnerabilities through **Security → Report a vulnerability** after private vulnerability reporting is enabled on the public repository. If unavailable, open an issue requesting a private contact route, without vulnerability details or sensitive data.

Never publicly include credentials, PINs, tokens, VINs, vault contents, raw captures, locations or memory dumps. Provide app/library versions, OS, safe impact and synthetic reproduction where possible. Do not operate someone else's vehicle or execute commands to demonstrate an issue.

No stable release is supported yet. Fixes require a new reviewed prerelease; do not replace published binaries/tags. Verify archive checksums and release evidence. Current Windows executables are unsigned.
